Custom theme for SEES — Smart Electrical Engineering Solutions (Makkah, Saudi Arabia).

== Description ==

Classic PHP theme with English and Arabic (RTL) support.

Requires these free plugins from wordpress.org:
* Polylang — English / Arabic content and language switcher
* Advanced Custom Fields — editable page fields (field groups load from /acf-json)
* Contact Form 7 — contact form

Content types registered by the theme: Solutions, Projects (with Project categories) and FAQs.
